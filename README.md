Event Registration System

## 🌐 Live Demo

🔗 https://swathigoud91.github.io/DevOps/

A simple and responsive Event Registration System built using HTML, CSS, and JavaScript. This project allows users to register for an event by entering their details through a user-friendly form. JavaScript is used for client-side validation to ensure valid user input before submission.

🚀 Features
Responsive registration form
Clean and modern user interface
Client-side form validation using JavaScript
Validation for required fields
Email format validation
Success message after successful registration
Beginner-friendly project structure
🛠️ Technologies Used
HTML5 – Structure of the webpage
CSS3 – Styling and responsive design
JavaScript (ES6) – Form validation and user interaction
📁 Project Structure
Event-Registration/
│── registration.html
│── style.css
│── index.js
└── README.md
▶️ How to Run
Clone the repository:
```
git clone https://github.com/your-username/Event-Registration.git
```
Navigate to the project folder:
```
cd Event-Registration
```
Open registration.html in your web browser.

No additional installations or dependencies are required.

📸 Preview

The application includes a responsive event registration form where users can enter their details and receive instant validation feedback before submitting.
